# gettext source download override

Conan Center recipe with the direct GNU HTTPS source URL and original source
checksum. Upstream build patches are downloaded by Conan into its source cache,
from commit `4d5b5d6e5ad87dd6f0d6ed1bdf589fa4bf437a99`, with SHA-256 verification.
No patch files or library source trees are stored in this repository.

Upstream: https://github.com/conan-io/conan-center-index/tree/4d5b5d6e5ad87dd6f0d6ed1bdf589fa4bf437a99/recipes/gettext/all
